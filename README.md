# Fundación Cultural Parada Literaria

Sitio web oficial de la **Fundación Cultural Parada Literaria** (Rancagua, Región de O'Higgins, Chile).

## Ejes de Trabajo
- **01 / Acceso:** Módulos de bibliotecas libres en centros de salud (CESFAM) y circulación de libros.
- **02 / Mediación:** Cuentacuentos, mandiles narrativos y proyectos textiles de memoria comunitaria.
- **03 / Formación:** Capacitaciones en fomento lector y literatura infantil y juvenil (LIJ).

## Tecnologías
- HTML5 semántico
- Tailwind CSS
- Tipografías: Libre Caslon Display, Cormorant Garamond, DM Sans
- JavaScript nativo
